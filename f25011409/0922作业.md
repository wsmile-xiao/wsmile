## 一 Ollama模型下载和调用

本机安装 Ollama 0.40.6，并使用本地 `qwen2:1.5b` 模型。模型下载命令如下：

```powershell
ollama pull qwen2:1.5b
ollama run qwen2:1.5b
```

原生 Ollama API 地址是 `http://127.0.0.1:11434/api/chat`。示例调用：

```powershell
$body = @{ model = "qwen2:1.5b"; messages = @(@{ role = "user"; content = "请用一句话介绍 Ollama" }); stream = $false } | ConvertTo-Json -Depth 5
Invoke-RestMethod http://127.0.0.1:11434/api/chat -Method Post -ContentType "application/json" -Body $body
```

项目中的 `ollama_service.py` 将本地模型包装成对外 HTTP 服务：

```powershell
python ollama_service.py
Invoke-RestMethod http://127.0.0.1:8000/health
```

服务提供 `/api/chat` 原生入口和 `/v1/chat/completions` OpenAI 兼容入口，默认监听本机 8000 端口。部署到局域网时可设置 `SERVICE_HOST=0.0.0.0`，并在防火墙和反向代理层做好访问控制，不直接暴露未鉴权服务。

## 二 不同调用方式的区别

| 调用方式 | 请求特点 | 适合场景 |
|---|---|---|
| Ollama API | 面向本地模型运行时，路径如 `/api/chat`，可控制模型、流式输出和本地参数 | 本机开发、实验和局域网服务 |
| OpenAI Chat Completions | 使用 `messages` 对话数组，生态兼容性好 | 迁移已有聊天机器人或 SDK |
| OpenAI Responses | 以 `input` 和 response 对象为中心，便于组合工具、文件和多模态能力 | 新应用、工具调用和复杂工作流 |
| Anthropic Messages | 使用 `system`、`messages` 和内容块，强调 Claude 风格的消息结构 | 已使用 Anthropic SDK 的应用 |

本项目同时提供 Ollama 原生接口和 OpenAI Chat Completions 兼容接口；Responses 与 Anthropic Messages 不是 Ollama 原生协议，需要由网关做字段转换后再调用本地服务。

## 三 可以给模型增加的外挂

- **工具调用**：联网搜索、计算器、数据库查询、文件读写和业务 API。
- **知识库/RAG**：把课程资料、企业文档切分后建立向量索引，检索相关片段再交给模型回答。
- **记忆**：保存会话摘要、用户偏好和长期事实，控制上下文长度并避免泄露隐私。
- **多模态输入**：图片、音频和 PDF 解析；需要模型本身或外部模型支持对应模态。
- **安全与观测**：提示词过滤、权限控制、敏感信息脱敏、日志、限流和回答评测。
